Le machine learning
Le machine learning (apprentissage automatique) permet à un ordinateur d'apprendre à partir d'exemples plutôt que de suivre des règles écrites à la main.

Programmation classique : données + règles → résultats
Machine learning : données + résultats attendus → règles (le modèle)

Exemple : pour détecter le spam, on ne code pas une liste de mots interdits. On fournit des milliers d'emails déjà classés, et l'algorithme découvre seul les motifs qui distinguent un spam d'un message normal.

Trois grandes familles :

Supervisé : les données sont étiquetées (prédire un prix, classer une image).
Non supervisé : pas d'étiquettes, le modèle trouve des groupes ou des structures.
Par renforcement : le modèle apprend par essais, récompenses et pénalités.
Le cycle d'un projet :

Collecter et préparer les données
Choisir un modèle
L'entraîner en minimisant son erreur
L'évaluer sur des données jamais vues
Le déployer
Piège principal : le surapprentissage. Un modèle qui apprend ses exemples par cœur échoue sur de nouvelles données. L'objectif est la généralisation.

Applications : recommandations, traduction, reconnaissance vocale, détection de fraude.
